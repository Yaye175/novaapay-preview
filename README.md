# NOVAAPAY — web preview

The app, running in a browser: **https://yaye175.github.io/novaapay-preview/**

This repository holds **build output only**. It is overwritten by CI on
every change; do not edit it by hand. The source is private.

A browser cannot exercise biometrics, real Keychain storage, or the PDF
statement — so "it works here" is not device verification.

Balances and transactions are sample data. Nothing here moves real money.
